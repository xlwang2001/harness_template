# Quality

## Required Proof of Work

Every agent handoff should include:

- commands run,
- test results,
- CI status when available,
- screenshots or video for UI changes,
- known risks and follow-up issues.

## Test Commands

Record at least one automated test command for this project.

Example:

```bash
make test
```

## Review Expectations

Review for problem fit, correctness, maintainability, and safety.
